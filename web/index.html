About

关于这个小站

这里是一个用 Node.js + SQLite 搭起来的博客地基。主库负责登记账号与站点配置，每个账号都拥有自己独立的文章库，互不打扰；前端是原生 HTML / CSS / JavaScript，没有构建步骤。

  • Node.js
  • SQLite
  • Vanilla JS
  • 账号分库
  • 零依赖

接口

公开只读 API 已经就绪：站点配置、数据统计、跨账号 Feed、账号文章、文章详情。写接口留到下一阶段。

背景图

桌面按 16:9、手机按 9:16 适配。当前背景是一张 1672 × 941 的插画，想在大屏上更清晰可以换成 2560 × 1440 的高清版本。

下一步
