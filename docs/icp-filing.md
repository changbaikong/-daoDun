## 二、你需要做的（腾讯云控制台，需本人操作）

### 0. 提交前确认

- [ ] 腾讯云账号已**个人实名认证**；
- [ ] 轻量应用服务器在广州地域，**包年包月**，购买时长 ≥ 3 个月，且备案期间**剩余有效期 ≥ 1 个月**（不够先续费）；
- [ ] 域名 `congyu.xyz` 已完成**域名实名认证**，实名信息与备案主体**完全一致**（姓名 + 证件号）；

- [ ] 如果刚做完域名实名，建议**等约 3 天**再提交备案（实名信息同步到工信部需要时间）。

### 1. 提交备案

腾讯云控制台 → **备案** → 开始备案（首次备案 / 新增网站按向导选择）：

1. 填写**主体信息**（个人：姓名、身份证号、手机号、应急联系方式、住址）；
2. 填写**网站信息**（网站名称、服务内容、服务类型；个人博客/展示类即可）；
3. 选择**备案云资源**：这台轻量应用服务器（可按提示生成备案授权码）；
4. 填写**域名**：`congyu.xyz`（能备案主域名即可，`www` 会自动覆盖）；
5. 上传证件、完成**人脸核验**；
6. 提交，等待腾讯云初审。

> 小提示：个人备案的网站名称不要出现公司、行业、新闻、论坛等敏感词；「刀盾的小屋」属于个人性质，通常可以，若被审核驳回按意见修改即可。

### 2. 审核流程（时间线）

| 阶段 | 时间 |
| --- | --- |
| 腾讯云初审 | 1–2 个工作日 |
| 工信部短信核验 | 收到短信后按提示完成（通常要求 24 小时内） |
| 管局审核 | 1–20 个工作日（各省不同，不能加急） |
| 结果通知 | 短信 + 邮件，获得备案号（形如 `粤ICP备xxxxxxxx号-1`） |

**审核期间网站不能通过域名对外访问**——现在的状态（域名 HTTPS 被拦、HTTP 跳 HTTPS）刚好符合，不用改服务器；继续用 IP 调试即可。
